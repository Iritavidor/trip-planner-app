# China Trip Planner

PWA לתכנון וניהול טיול 20 יום לסין. עברית RTL, עובד אופליין.

## הרצה
```
npm install
npm run dev
```

## בנייה
```
npm run build
npm run preview
```

## מצבים
- **תכנון** – עריכת כל נתוני הטיול (סקירה, טיסות, מלונות, 20 ימים, אריזה).
- **טיול** – תצוגה גדולה לקריאה בלבד, נפתח אוטומטית על היום הנוכחי לפי תאריך.

הנתונים נשמרים ב-localStorage. ייצוא/ייבוא JSON זמין בכותרת.

## אייקונים PWA
שים `icon-192.png` ו-`icon-512.png` ב-`public/`.
